Root Ingrowth Data QAQC

For the Root Ingrowth Data QAQC script, programs are used for error checking root ingrowth data by running QA/QC programs and generating the root ingrowth output file for transfer

Note: For 2022 data, this is the year that we switched from SAS data processing / QAQC to using R. Within the data files of this year, you will see output files from both SAS and R (distinguished by _R at the end of exported .csv files). 


Make sure to updated YEAR within each file before saving to new folder
